Quick Install (Arch Linux ARM64)

Install the 8 DKMS kernel modules and full user-space stack directly, or build a native pacman package with makepkg.

git clone https://github.com/robertijtsma/surface-pro-x-sq2-linux.git
cd surface-pro-x-sq2-linux

# Option A: Direct DKMS + user-space installer
sudo ./scripts/install-sq2-dkms.sh
sudo ./scripts/install-sq2-userspace.sh

# Option B: Native Arch Linux ARM package
cd packaging/arch && makepkg -si

# Verify all 15 subsystems
./scripts/surface-sq2-diag.sh
